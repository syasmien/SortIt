# SortIt! Malaysia ♻️

### A Recycling Guide & Locator App

SortIt! Malaysia is a mobile app prototype designed to promote responsible recycling practices in Malaysia. It helps users identify recyclable materials, understand proper waste sorting methods, and locate nearby recycling centres through a user-friendly interface.

## Overview

Improper waste disposal and limited access to reliable recycling information can discourage people from recycling. SortIt! Malaysia aims to make recycling information more accessible and encourage sustainable habits through educational content, location-based services, and engaging community features.

## Key Features

- **Recycling Guide:** Learn how to sort recyclable materials using visual guides, bin colour codes, and plastic identification.
- **Recycling Centre Locator:** Find nearby recycling facilities using map and GPS-based features.
- **QR Code & Recycling Log:** Support recycling activity tracking through user profiles and QR codes.
- **Points & Rewards:** Encourage recycling through points and redeemable rewards.
- **Educational Quizzes:** Improve recycling knowledge through interactive quizzes.
- **Community Leaderboard:** View top recyclers and encourage participation.
- **Sustainability Education:** Explore educational content and infographics related to responsible recycling and SDG 13: Climate Action.

## Design Process

This project follows the **User-Centred Design (UCD)** methodology:

1. Understand users' context through empathy mapping and user personas.
2. Specify user requirements, tasks, and goals.
3. Design the app interface and user interactions.
4. Evaluate usability using the System Usability Scale (SUS).

## Usability Evaluation

The project report recorded an average System Usability Scale (SUS) score of **72.5**, based on feedback from 11 participants.

## Tools & Methods

- Figma — UI/UX design and interactive prototyping
- User-Centred Design (UCD)
- Empathy Mapping and User Personas
- System Usability Scale (SUS)
